Add the third instance of the `client/{service}/` triple, then hang the map image off it — with the Mapbox call strictly off the critical path.

`MapboxProperties` (new, package `com.tripflow.backend.client.mapbox`): `@ConfigurationProperties(prefix = "mapbox")` record of `String baseUrl, String accessToken, String style, Duration connectTimeout, Duration readTimeout`, with a `toString()` override that routes `accessToken` through `SecretMask.mask(...)` and leaves the other fields plain — exactly as `OrsProperties` does.

`MapboxClientConfig` (new): `@Configuration @EnableConfigurationProperties(MapboxProperties.class)`, one `@Bean RestClient mapboxRestClient(MapboxProperties props, RestClient.Builder builder)` copying `OrsClientConfig`'s timeout/request-factory wiring and `.baseUrl(props.baseUrl())`. Stop there. Do NOT carry over either of the two builder-level default request headers `OrsClientConfig` sets: the Static Images API authenticates by an `access_token` query parameter only (a header-authenticated request silently 401s), and the response is binary, so a JSON content-type default is dead config. The resulting bean should set base URL and request factory and nothing else.

`MapboxClientException` (new, package `com.tripflow.backend.exception`): a `RuntimeException` subclass with `(String message)` and `(String message, Throwable cause)` constructors, mirroring `OrsClientException`.

`GlobalExceptionHandler` (modified): add a third `@ExceptionHandler(MapboxClientException.class)` method directly beneath `handleGeminiFailure`, same body shape — `log.error("502 Bad Gateway on {}: {}", req.getRequestURI(), ex.getMessage(), ex)` then `error(HttpStatus.BAD_GATEWAY, "Map snapshot service is temporarily unavailable", req, null)`. This is a safety net for any future caller; the PDF path deliberately never reaches it.

`MapboxClient` (new): `@Slf4j @Component @RequiredArgsConstructor`, injecting the `RestClient` and `MapboxProperties`. Expose `Optional<byte[]> staticSnapshot(String routeGeometryJson, List<double[]> stopCoordinates)`.
- Return `Optional.empty()` immediately, with no HTTP call, when `props.accessToken()` is null or blank — this is what makes the unprovisioned-token case a boot-safe no-op rather than a startup failure.
- Return `Optional.empty()` when there is neither a route geometry nor at least one stop coordinate.
- Build the overlay segment: when `routeGeometryJson` is non-null, `"geojson(" + URLEncoder.encode(routeGeometryJson, StandardCharsets.UTF_8) + ")"`. `Trip.routeGeometry` is already a stored GeoJSON LineString string and the Static Images API takes GeoJSON overlays natively, so it drops straight in — do not write or import a coordinate-compression algorithm to transform it first. When it is null (D-04: trip never optimized), build comma-separated `pin-s+{hex}({lon},{lat})` marker overlays from the stop coordinates instead, with no route line.
- Guard the URL length before sending: assemble the full request URI, and if its length exceeds a named constant set at 8000 (margin under Mapbox's documented 8,192-character cap), discard the `geojson()` overlay and retry the assembly with the marker-only overlay.
